# /impl — реализация утверждённого плана

Ты работаешь на стадии IMPL пайплайна. Активная задача: `{{SLUG}}`.

## Что сделать

1. Прочитай план с диска: `docs/tasks/{{SLUG}}/plan.md` (и спеку при необходимости).
2. Реализуй задачи по порядку зависимостей (`depends_on`).
   Для каждой задачи:
   - правь только файлы из `files` (и очевидно связанные)
   - после реализации прогони её `validation`-команду
   - если validation падает — исправь и повтори (максимум 3 попытки; дальше — стоп и отчёт)
3. Код пиши ТОЛЬКО в каталоге проекта (`<project-name>/`, для этого репо — `extensions/`,
   `skills/`), не в корне и не в `docs/`.
4. По завершении каждой задачи записывай короткий отчёт в
   `docs/tasks/{{SLUG}}/reports/task-NN.md`: что сделано, файлы, результат validation.
5. В чате: итоговая сводка (задача — статус — validation) и предложение `/stage next` (TEST).

## Правила

- Один шаг за раз, проверка после каждого (incremental).
- Ошибка без очевидного фикса — стоп, отчёт, ждать решения (stop-on-failure).
- Не трогай `docs/` вне `docs/tasks/{{SLUG}}/` (гейт заблокирует).
