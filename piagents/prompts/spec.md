# /spec — спецификация задачи

Ты работаешь на стадии SPEC пайплайна. Активная задача: `{{SLUG}}`.

Вход от пользователя:

$ARGUMENTS

## Что сделать

1. При необходимости задай уточняющие вопросы (не более 3), если вход неполный.
2. Составь спецификацию задачи со следующими разделами:
   - **Цели** — что должно получиться (измеримо)
   - **Критерии приёмки** — список проверяемых условий
   - **Ограничения** — чего делать нельзя, с чем совместимость нужна
   - **Контекст** — минимально необходимые ссылки на файлы/доки (MVI: ссылки, не пересказ)
3. Запиши спецификацию в файл `docs/tasks/{{SLUG}}/spec.md` (создай каталог).
   Артефакты задач живут ТОЛЬКО там — не в корне репо и не в чате.
4. В чате дай только краткое резюме (5–7 строк) и предложи пользователю команду `/plan`.

## Правила

- НЕ изменяй код проекта — стадия SPEC этого не разрешает (гейт заблокирует).
- Не выдумывай требования — фиксируй только то, что следует из входа; допущения помечай `(?).
