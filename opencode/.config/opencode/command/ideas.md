# Idea Backlog Management

Управление бэклогом idea-inbox. Аргументы: $ARGUMENTS

- Без аргументов — вызови тул `idea_list` и выведи результат как есть (готовая таблица).
- `run <id>` — вызови тул `idea_list`, возьми текст идеи и выполни её сам прямо здесь: делегируй подходящему сабагенту (task tool), используй нужные скилы; по завершении вызови `idea_update` со status="done".
- `start <id>` — вызови тул `idea_start`: идея уйдёт в фоновую сессию и станет ◐ in_progress.
- `done <id>` — вызови тул `idea_update` со status="done".
- `documented <id>` — вызови тул `idea_update` со status="documented": идея уйдёт из сайдбара в архив.
- Любой другой аргумент — выведи краткую справку по этим формам.

Отвечай максимально коротко: результат тула плюс одна строка вывода. Не развёртывай идеи в планы и не начинай выполнять их из этой команды (кроме формы `run` — там выполняй сразу).
