It's own config files, for personal use.
For fast reuse this files need GNU stow app is installed
go to folder and type:
'stow nvim # as example`

Cross-platform: used on several machines (per-machine branches; repo expected at `~/dotfiles`).
Machine-specific data (keys, IPs, sessions, runtime state) is NOT tracked — each machine keeps its own locally.
