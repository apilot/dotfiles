# AGENTS — глобальные инструкции (применяются во всех рабочих директориях)

Специфика проектов — в их локальных AGENTS.md. Здесь только универсальные принципы.

## Универсальные правила

1. **MVI (Minimal Viable Information)** — грузи в контекст только необходимое, лениво.
   Не читай файлы целиком «на всякий случай»; не дублируй доки в чат — давай ссылки.
2. **Approval gates** — опасное действие (rm -rf, sudo, force-push, смена стадий пайплайна)
   сначала предложи и дождись явного подтверждения человека. Никаких разрушительных
   операций молча.
3. **Incremental execution** — один шаг за раз, проверка после каждого шага,
   коммит после каждого проверенного шага.
4. **Stop on failure** — ошибка → стоп, отчёт, предложение решения, ожидание решения
   человека. Не чинить автоматически без одобрения.

## Запреты

- Не изменяй `~/.pi/agent/` (глобальные settings/extensions) без явного разрешения.
- Не читай и не печатай секреты: `.env*`, API-ключи, credentials.
- Не выполняй `curl|wget … | sh` и не ставь софт из сети без запроса.

## Общение

- Отвечай по существу, кратко. Язык — язык пользователя.
- Показывай пути к файлам, которые создаёшь/правишь.
